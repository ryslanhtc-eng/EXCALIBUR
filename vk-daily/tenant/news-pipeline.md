# News pipeline — Уфа, не федеральная вода

Cursor Cloud собирает **одну** правду дня. Grok Bot её не ищет и не переписывает, только публикует готовый пост.

## Источники (по убыванию)

1. Локальные: РБК Уфа, Башинформ, UFA1, Ъ-Уфа, сайт администрации — если цифра свежая.
2. Федеральные обзоры **только** если в таблице есть строка «Уфа» и метод понятен.
3. Нельзя: телеграм-слухи, «мне ИИ сказал», чужой город как будто наш.

Цифра без даты и без того, *что именно* мерили (квадрат первички / средняя квартира / вторичка) — не берём.

## Угол

Не «новость ради новости». Вопрос читателя из Сипайлово / Дёмы:

- мне сейчас покупать или пересчитать?
- не врёт ли объявление?
- что будет с платежом, если семейная программа сузится?

## Жёсткие фильтры

- Город = Уфа. Районы из `tenant.json`.
- Не смешивать методики: 177 тыс. за строящийся квадрат и 197,8 тыс. за первичку — разные линейки, в одном посте одна.
- Ставки банков и «официальный прайс Самолет Плюс» не выдумывать. Если нет свежей оферты в фактах — говори качественно: «пересчитайте платёж», без числа.
- Ссылки в пост не ставить. Источник можно назвать словами: «РБК Недвижимость, август».

## Куда класть факты

- Оперативно: `vk-daily/data/news-bank.json` (поле на дату).
- Либо JSON-файл в `--news-json` на прогоне.
- Скрипт выбирает запись с `date <= сегодня` (таймзона Уфы).

Cloud Agent может переписать `post.txt` живым языком **после** фактов, затем прогнать валидатор и cover. Нельзя публиковать обложку-заглушку.
