# Cover headline & description — арт-директор

На журнальной обложке ВК всегда два текстовых элемента в левом нижнем углу: **HEADLINE** и **DESCRIPTION (dek)**.

## 1. HEADLINE (Заголовок кадра)

- **4–8 слов** (кириллица, обычные пробелы).
- **Без точки** в конце. Без `!` `?` `…`.
- **Без эмодзи**.
- **Без метро в любой форме** (никаких «метро», «подземка», даже как отрицание).
- **Бытовая городская польза** (ЖКХ, квитанции, тепло, ремонт, семейный платёж), а не узкая статистика цен.
- Читается с телефона за секунду.

### Примеры хороших HEADLINE:
- «Зима в городе: считаем платёж» (5 слов)
- «Проверь теплосчётчик до первой квитанции» (5 слов)
- «Как не переплатить за тепло зимой» (6 слов)
- «Готовим радиаторы и квитанции к осени» (6 слов)
- «Сколько Уфа заплатит за отопление зимой» (6 слов)

### Запрещено:
- Любые фразы со словом «метро» («в Сипайлово нет метро», «метро рядом» — абсолютный запрет).
- «Срочно покупай до подорожания.» (точка, давление).
- Узкие статистические лекции («РБК: квадрат первички вырос на 1,6%»).

## 2. DESCRIPTION / DEK (Обязательный подзаголовок)

- **Обязателен** на обложке по канону первой утверждённой журнальной обложки.
- 1–2 короткие строки под хедлайном (2–10 слов).
- Раскрывает практическое действие читателя.
- Чёткий читаемый белый шрифт.

### Примеры DESCRIPTION / DEK:
- «Проверь теплосчётчик до квитанции.»
- «Как не переплатить за отопление в Уфе.»
- «Три шага до первых зимних счетов.»
