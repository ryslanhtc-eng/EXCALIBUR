# Cover style — VK daily, Руслан Мухтаров

Одна обложка на пост. Это **не** quad-canvas блога Excalibur и не мем-коллаж «Ковчег».

## Кадр

- Горизонталь **16:9** (или **4:3**) под ленту и сниппеты ВК.
- Фотореализм, как кадр с телефона / простой репортаж. Не CGI-глянец, не сток «успешный риелтор».
- Герой — **тот же человек, что на селфи** в `vk-daily/refs/`. Лицо не менять. Одежду можно.
- Акцент по умолчанию: **синий `#2F7BFF`** как цвет дизайна (полоса, фон, элементы оформления). **Запрещено** писать код цвета или хекс на предметах (никаких надписей «#2F7BFF» на кружке, никаких RAL номеров). Не розовый блог-маркер, не красный «срочно».

## Композиция

Каждый прогон — **новый** id из `vk-daily/data/compositions.json`. Не повторять ракурс, локацию и жест предыдущего run.

В кадре всегда:

1. Узнаваемый Руслан (лицо с refs).
2. Крупный кириллический headline (см. `cover-headline.md`).
3. Синий акцент: стена, бейка, скотч, кружка, папка, небо, световая полоса.
4. Уфимский быт: двор, новострой, вторичка, стол с планировкой, Балкон на Белую, панельки Сипайлово. Без московского метро, без подземки «как будто она есть».

## Текст на картинке

Только headline. Без мелкой простыни, без URL, без телефона, без «жми», без эмодзи.

## Негатив

метро / subway / underground station in Ufa, Moscow skyline, Red Square, extra fingers, watermark, English poster, corporate stock smile, neon cyberpunk, fake newspaper with unreadable glyphs, another person's face.
