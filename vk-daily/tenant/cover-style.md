# Cover style — VK daily, Руслан Мухтаров

Одна обложка на пост. Это **не** quad-canvas блога Excalibur и не мем-коллаж «Ковчег».

## Кадр

- Вертикаль **3:4** под ленту ВК (KIE gpt-image-2 при 2K не принимает 4:5).
- Фотореализм, как кадр с телефона / простой репортаж. Не CGI-глянец, не сток «успешный риелтор».
- Герой — **тот же человек, что на селфи** в `vk-daily/refs/`. Лицо не менять. Одежду можно.
- Акцент по умолчанию: **синий `#2F7BFF`** (бейдж «ПЛЮС» на чёрной толстовке). Можно лёгкий голубой кашкорсет, как на светлом селфи. Не розовый блог-маркер, не красный «срочно».

## Композиция и ротация поз/гардероба

Каждый прогон — **новый** id из `vk-daily/data/compositions.json` и **новый** референс позы/гардероба из каталога `vk-daily/refs/poses-wardrobe/` (ротируется через `used_pose_refs` в `memory/vk-daily/state.json`). Не повторять ракурс, гардероб, локацию и жест предыдущего run.

В кадре всегда:

1. Узнаваемый Руслан (лицо строго с селфи-refs, лица моделей из каталога поз категорически запрещено переносить).
2. Поза, посадка одежды и вайб из выбранного референса каталога `poses-wardrobe/` (01-06).
3. Крупный кириллический headline (см. `cover-headline.md`).
4. Синий акцент `#2F7BFF`: бейдж «ПЛЮС», деталь одежды, стена, бейка, скотч, кружка, папка, небо, световая полоса.
5. Премиальный вид эксперта в сочетании с уфимской средой: двор, новострой, вторичка, стол с планировкой, балкон на Белую, панельки Сипайлово, Дёма, центр Уфы. Без московского метро, без подземки «как будто она есть».
