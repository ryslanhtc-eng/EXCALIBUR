# Emoji rules — только эмоция

В постах VK daily эмодзи — это **чувство**, не буллет и не иконка услуги.

## Можно (редко)

`😅 😄 😊 😌 🤔 😬 🔥 💔` и близкие по смыслу лица/чувства.

Максимум **два** эмодзи на весь пост. Лучше один. Можно ноль.

Ставь туда, где живой человек усмехнулся бы. Не в каждое предложение.

## Нельзя

Декор, объекты, стрелки, флаги, «профессиональные» значки:

`🏠 🏡 🏢 📍 📌 📞 👉 ⬇️ ✅ ❌ 🔹 ▪️ ✔️ 📊 📈 💰 🔑 🛠 ✨ 🇷🇺 🔵 🔹`

Не заменять ими абзацы. Не ставить в headline обложки. Не ставить в начало каждой строки.

## Проверка

Скрипт валидации режет пост, если:

- есть запрещённый объектный эмодзи;
- больше двух эмодзи;
- эмодзи в первой строке-заголовке обложки (cover headline отдельно, там ноль).
