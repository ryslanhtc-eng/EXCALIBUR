## Лицо (lock)

- Мужчина ~40, короткие тёмные волосы, бока короче, верх чуть длиннее
- Светло-серые / серо-голубые глаза
- Живая улыбка, верхние зубы видны, без «стоковой» растяжки рта
- Лёгкая щетина, овальное лицо, без очков
- Не менять возраст, не «улучшать» в другую внешность, не подменять другим человеком

## Режим без лица (no-person cover)

Если владелец запрашивает обложку без своего лица / без людей (no-person cover):
- НЕ передавать селфи в KIE.
- НЕ использовать image-to-image с лицом.
- Использовать text-to-image (`gpt-image-2-text-to-image`), 16:9, журнальный стиль (глянец, DARK/Gilded), предметный акцент + архитектура/набережная Уфы.

## Свободно

Одежда, жест, локация, свет — по `compositions.json`. Толстовки с селфи копировать не обязательно.

## Для KIE i2i

В `input_urls` — **оба** селфи, если файлы на месте. Промпт: preserve exact facial identity from references, new scene.
