# Pose & Wardrobe Reference Catalog — Руслан Мухтаров (VK daily)

Каталог референсов поз, стиля одежды и кинематографичного/репортажного вайба для генерации обложек ВКонтакте.

## Ключевые правила и ограничения (СТРОГО)

1. **FACE LOCK — ТОЛЬКО ИЗ СЕЛФИ РУСЛАНА (`vk-daily/refs/ruslan_selfie_{blue,black}.jpg`)**  
   Лицо генерируемого персонажа ВСЕГДА берётся исключительно из подтверждённых селфи Руслана.  
   Ни при каких обстоятельствах нельзя копировать лица моделей из референсов каталога!  
   В негативном промпте и правилах генерации зафиксировано: «never copy foreign faces, preserve exact facial identity of Ruslan Mukhtarov from face refs».

2. **НАЗНАЧЕНИЕ КАТАЛОГА: ТОЛЬКО ПОЗЫ, ГАРДЕРОБ И ВАЙБ (Pose / Wardrobe / Vibe only)**  
   Данные изображения служат исключительно образцами:
   - естественных мужских поз (сидя в кресле, стоя у стены, работа за столом, живой жест с часами или документами, непринуждённый шаг);
   - посадки костюма и smart-casual одежды (тёмно-синий костюм, белый воротник, строгий чёрный костюм с галстуком, монохромная рубашка с белыми/тёмными брюками, серый костюм с белой футболкой и кедами, рабочий оверсайз/слои);
   - композиции кадра, ракурсов камеры и распределения света (студийный мягкий свет, естественный оконный свет, офисный репортаж).

3. **РОТАЦИЯ КАЖДЫЙ ПРОГОН (Rotate every cover)**  
   Каждая новая обложка поста выбирает **другой** референс позы/гардероба по кругу.  
   История использованных референсов сохраняется в `memory/vk-daily/state.json` в ключе `used_pose_refs`.  
   Один и тот же референс не повторяется подряд.

4. **СОЧЕТАНИЕ С УФОЙ И КОРПОРАТИВНЫМ СТИЛЕМ САМОЛЕТ ПЛЮС**  
   Поза и гардероб из референса гармонично соединяются с:
   - реальной уфимской локацией (жилые кварталы Уфы, Сипайлово, Дёма, набережная Белой, офис на ул. Правды, 10, новостройки и уютные интерьеры без московского метро);
   - фирменным синим акцентом `#2F7BFF` (бейдж «ПЛЮС», деталь одежды, папка, кружка, интерьерный элемент);
   - крупным читаемым кириллическим заголовком (4–8 слов без точки и эмодзи).

## Загрузка бинарных файлов

Если исходные бинарные JPEG-файлы отсутствуют в рабочей среде (например, из-за сетевых ограничений Cloud Agent), пайплайн ожидает их размещение по каноническому пути:
`<PROJECT_ROOT>/vk-daily/refs/poses-wardrobe/<filename>.jpg`.

Внешний бот / оркестратор (Grok Bot) может загрузить или закоммитить бинарные файлы в эту папку. Код генератора (`generate_cover.py`) корректно валидирует наличие файлов, использует их в prompt-инструкциях и i2i-пайплайне, а при отсутствии физического файла безопасно применяет текстовый дескриптор стиля из каталога без падений.
